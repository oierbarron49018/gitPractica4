# gitPractica4(Gestor Citas Taller)
<h1>Guía de Uso: Sistema de Citas para Taller</h1>

<h2>¿Qué es este programa?</h2>
<p>Es una aplicación sencilla para gestionar la atención en el taller. Permite guardar los datos del cliente y su vehículo, programar la fecha de la cita y calcular el precio final del trabajo solicitado.</p>

<h2>Pasos para utilizar la aplicación</h2>

<h3>1. Navegar por el menú</h3>
<p>Al arrancar el programa se muestra un menú en pantalla. Escribe el número de la opción que quieras usar y pulsa la tecla Enter.</p>

<h3>2. Dar de alta una cita</h3>
<p>Selecciona la opción 1 para ingresar el nombre del cliente, la matrícula, la marca y el modelo del coche. A continuación, escribe la fecha y la hora en formato día/mes/año hora:minuto (por ejemplo: 25/05/2026 10:30) y elige el tipo de reparación o revisión requerida.</p>

<h3>3. Obtener el precio final</h3>
<p>Selecciona la opción 3 para calcular el importe a cobrar. El programa aplica automáticamente el precio del servicio y descuenta un porcentaje si la matrícula cumple ciertas condiciones: un 20% si termina en ECO, un 15% si empieza por H o un 10% si contiene 00.</p>

<h3>4. Finalizar la sesión</h3>
<p>Selecciona la opción 4 para salir de la aplicación cuando hayas terminado de registrar o consultar la información.</p>
